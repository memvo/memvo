II Anatomy of a vault

Vault. Accounts. Periods. Entries. Receipts.

The way you already think about money, kept on disk. Nothing is summarised on the way in, so nothing can drift from what the bank sent you.

  1. V · vault

    The vault

    One SQLite file at ~/.memvo/vault.db. Copy it, back it up, delete it. Nothing else holds your data.

  2. A · account

    Accounts

    Checking, savings, card, broker. Each import names its account, so totals never mix.

  3. P · period

    Periods

    Months. memvo periods shows money in and out for each one, per account.

  4. E · entry

    Entries

    One transaction, stored as the exact text from the file, with its amount as an exact integer, never a float.

  5. R · receipt

    Receipts

    Where an entry came from: file, line range, file hash, row hash. Every answer carries one.

IV How it works

Five pieces. No cloud. No keys.

01

Local-first

Python standard library only. No network calls, no telemetry, no account. It works on a plane.

Dependencies · none

02

Verbatim

CSV, OFX and QFX, English or Indonesian headers, 1,234.56 or 1.234,56. Bad rows are listed with a reason, never guessed.

Formats · CSV · OFX · QFX

03

Audit

Re-hashes every source and checks each stored row against the file on disk. Flags overlapping exports.

Exit code · 0 ok · 2 mismatch

04

Reconcile

Checks running balances row by row and compares totals with the balance your statement states.

Sample · difference 0.00

05

MCP, read-only

Seven tools for agents: search, entry, accounts, periods, audit, reconcile, stats. None can write.

Command · memvo mcp

V Begin

Open your vault.

Real output from the sample statement in the repository. Your own statements never leave the folder you run this in.

~/statements · bash
$ memvo init
Vault created at ~/.memvo/vault.db
$ memvo import checking.csv --account checking
checking: 6 entries added from checking.csv (csv)
source sha256 7e61003a02cb6628…
columns: date=Date, amount=Amount, description=Description, balance=Balance
$ memvo search streamly
2026-11-05          -17.99  checking     STREAMLY SUBSCRIPTION, MONTHLY
    e_87f7eaf199f9cde5  checking.csv:7
